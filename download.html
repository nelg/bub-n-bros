Which is which?

portable

The Rust client, bubbros-client, with the game server built in. One program: joins games on your network, or plays alone when there is none.

server-portable

The game server, bubnbros-server, as one program with its own Python inside. bubnbros-server --web opens the web launcher. The Linux packages add the Rust client.

python

The classic game for your own Python 3 with pygame: the server, the web launcher (BubBob.py) and the Python clients. The Linux packages add the Rust client.

The three Linux packages do the same job and replace each other: install only one. Want to build it yourself? See INSTALL.txt.

The Bub's Brothers was written by Armin Rigo, with graphics by David Gowers and sounds, music and levels from McSebi's Bub & Bob. See the original website. This update is on GitHub.
